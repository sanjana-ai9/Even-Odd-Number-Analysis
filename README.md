# Even-Odd Number Analysis

## About the Project

This is my fifth task at Veda Technology. In this project, I created a simple Python program to identify even and odd numbers from a list and find the largest and smallest numbers.

## Objective

The objective of this project is to practice Python loops, conditional statements, and basic numerical processing.

## Tools Used

* Python
* Jupyter Notebook

## Concepts Used

* Lists
* For loop
* If-else statements
* Modulo operator (%)
* append()
* max() and min()

## Output

The program displays:

* The original list of numbers
* The list of even numbers
* The list of odd numbers
* The largest number
* The smallest number

## What I Learned

Through this task, I learned how to separate even and odd numbers using a loop and condition. I also practiced finding the largest and smallest values in a list using Python's built-in functions.

This task helped me improve my basic Python programming skills and understand how to process numerical data.
